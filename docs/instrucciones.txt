=== SALUD INTEGRAL — PROYECTO DISEÑO WEB II ===

REQUISITOS
- PHP 8+, MySQL/MariaDB, Apache (XAMPP/WAMP).
- Navegador moderno con soporte HTML5 video.

INSTALACIÓN
1. Copiar la carpeta salud-integral/ en htdocs.
2. Importar sql/script.sql en phpMyAdmin.
3. Generar hash real de contraseña:
   php -r "echo password_hash('12345678', PASSWORD_DEFAULT);"
   Reemplazar el hash del usuario admin en la tabla usuarios.
4. Editar config/conexion.php con credenciales locales.
5. Abrir http://localhost/salud-integral/
